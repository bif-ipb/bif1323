MATERI / PERTEMUAN 05

SQL Lanjut dan Query Biologis

Menghubungkan, menyaring, merangkum, dan menginterpretasikan data biologis dari beberapa tabel menggunakan query SQL lanjut.

Tujuan Praktikum

  1. Memilih dan menggunakan INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN, CROSS JOIN, dan self join sesuai kebutuhan penggabungan data.
  2. Menggunakan WHERE, ORDER BY, fungsi agregasi, GROUP BY, HAVING, dan subquery untuk menjawab pertanyaan pada data biologis.
  3. Memeriksa kardinalitas, nilai NULL, dan pertambahan baris, kemudian menginterpretasikan hasil query sesuai cakupan dataset.

Pendahuluan

Pada Pertemuan 4, mahasiswa telah mempelajari perintah SQL dasar untuk membuat struktur serta menambahkan, membaca, mengubah, dan menghapus data. Pertemuan 5 melanjutkan kemampuan tersebut dengan menggunakan query untuk menghubungkan dan merangkum informasi dari beberapa tabel.

Praktikum menggunakan basis data BioSQLite yang memuat data genom, RNA-seq, mutagenesis, anotasi Gene Ontology, dan pathway Plasmodium falciparum. Basis data dipulihkan dari berkas cadangan PostgreSQL yang disediakan sehingga mahasiswa dapat langsung bekerja dengan dataset yang saling berhubungan.

Setiap pertanyaan diterjemahkan menjadi pilihan tabel, kolom pencocokan, kondisi penyaringan, jenis penggabungan, dan bentuk hasil yang diperlukan. Mahasiswa kemudian membandingkan hasil query dengan prediksi serta menafsirkan hasil sesuai cakupan dataset. Screenshot digunakan sebagai bukti pelaksanaan, sedangkan penjelasan tertulis menunjukkan pemahaman terhadap hasil.
