MATERI / PERTEMUAN 04

SQL Dasar

Membuat struktur tabel dan mengelola data biologis menggunakan perintah dasar SQL pada PostgreSQL.

Tujuan Praktikum

  1. Membuat dan mengubah struktur tabel data biologis menggunakan CREATE TABLE dan ALTER TABLE.
  2. Menambahkan, menampilkan, memperbarui, dan menghapus data menggunakan INSERT, SELECT, UPDATE, dan DELETE.
  3. Menjalankan skrip SQL serta memeriksa hasil operasi dan penerapan constraint pada PostgreSQL.

Pendahuluan

Pada pertemuan sebelumnya, rancangan basis data telah dipetakan menjadi tabel, atribut, primary key, foreign key, dan integrity constraint. Rancangan tersebut selanjutnya diwujudkan dan dikelola pada database management system (DBMS) menggunakan Structured Query Language (SQL).

Praktikum ini menggunakan data biologis berupa katalog gen Plasmodium falciparum 3D7 dan anotasi pathway. Data tersebut menyimpan identitas gen, lokasi gen pada sekuens referensi, arah strand, serta hubungan gen dengan pathway. Dataset yang digunakan merupakan subset gen yang berkaitan dengan tiga pathway, sehingga hasil pengamatan dan interpretasi hanya berlaku dalam subset ini.

Mahasiswa akan menggunakan CREATE TABLE untuk membuat tabel, ALTER TABLE untuk mengubah struktur tabel, serta INSERT, SELECT, UPDATE, dan DELETE untuk mengelola data. Setiap perintah dijalankan secara bertahap agar perubahan pada struktur dan isi basis data dapat diamati.
